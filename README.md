# LibreAudit: RFID Library Access Ledger

LibreAudit is a decentralized system designed to bridge physical hardware access logs with the immutability of the blockchain. Originally built for an RFID-based library entry system, it ensures that access records are transparent, tamper-proof, and permanently archived.

## Core Features
The system processes Excel-based entry logs generated by RFID hardware and anchors them to the Polygon blockchain. It provides a secure audit trail for institutions that require high-integrity record keeping.

- Data Integrity: Converts hardware-generated spreadsheets into JSON and pins them to IPFS for decentralized storage.
- Blockchain Anchoring: Records the IPFS Content Identifier (CID) on a smart contract, providing a permanent proof of existence for every log batch.
- Dual-Mode Execution: Features a production mode for real blockchain deployment and a simulation mode for instant, gasless demonstrations.
- Modern Interface: A minimalist dashboard designed for clarity and efficiency in high-traffic administrative environments.

## Technical Architecture
The project is built on a modern full-stack architecture:
1. Frontend: React and Vite, utilizing Framer Motion for subtle interactive transitions and Lucide for iconography.
2. Backend: Node.js and Express, handling file processing via the XLSX library and IPFS integration via Pinata.
3. Smart Contract: Written in Solidity and managed with Hardhat, optimized for low-cost data storage on the Polygon Amoy testnet.

## Setup and Installation

### Smart Contract
1. Navigate to the contracts directory and configure the environment variables in a .env file, including your private key and RPC URL.
2. Compile and deploy the contract using the provided deployment script.
3. Record the deployed contract address for the backend configuration.

### Backend
1. Navigate to the backend directory and update the .env file with your Pinata API credentials and the smart contract address.
2. Start the server using Node.js.

### Frontend
1. Navigate to the frontend directory and install dependencies.
2. Launch the development server to access the dashboard.

## Usage in Simulations
For demonstration purposes, the system includes a simulation toggle. In this mode, the backend bypasses the blockchain gas requirement and simulates the recording process in local memory. This allows for a complete walkthrough of the audit flow without needing test tokens or wallet signatures.

## Security Considerations
LibreAudit is designed with security in mind, utilizing environment variables for all sensitive keys. The smart contract is architected to minimize on-chain data footprint, thereby reducing gas costs while maintaining a complete audit trail of the IPFS-hosted log files.
